
# Linear Regression from Scratch Using PyTorch

## Overview

This project demonstrates the implementation of Linear Regression using PyTorch tensors and automatic differentiation (Autograd).

The objective is to understand how a machine learning model learns its parameters through forward propagation, loss calculation, backpropagation, and gradient descent.

## Learning Objectives

- Understand PyTorch tensors.
- Initialize model weights and bias.
- Implement forward propagation.
- Calculate Mean Squared Error (MSE).
- Understand automatic differentiation using Autograd.
- Perform gradient descent manually.
- Understand the model training process.

## Technologies Used

- Python
- PyTorch
- NumPy
- Pandas
- Scikit-learn
- Jupyter Notebook

## Implementation

The project covers the following steps:

1. Dataset loading
2. Data preprocessing
3. Training, validation and test split
4. Tensor conversion
5. Model parameter initialization
6. Forward pass
7. Loss calculation
8. Backpropagation using Autograd
9. Gradient descent optimization
10. Model evaluation
